# AGENTS.md

Instructions for AI coding agents working in this repository. Humans: see
[CONTRIBUTING.md](CONTRIBUTING.md), which this summarises.

## What this is

RSVP Reader: a client-only, offline speed-reading app (React 19 + Vite + TypeScript strict,
Dexie, zustand, MuPDF WASM, Tesseract). One web build is shipped as a PWA, a Tauri desktop app
and a Capacitor Android app. **There is no server, and there must never be a network call at
runtime.**

Read [ARCHITECTURE.md](ARCHITECTURE.md) before structural changes. The subsystem docs are in
[docs/architecture/](docs/architecture/README.md).

## Commands

```bash
pnpm install
```

```bash
pnpm format:check && pnpm lint && pnpm typecheck && pnpm test && pnpm build
```

A task is not finished until that whole line passes. For a UI change, also run the smoke test in
CONTRIBUTING.md against `pnpm dev` (port 5180) and check the console for errors.

## Rules

1. **Respect the layers.** `core` ← backend (`parse`, `pdf`, `ocr`, `storage`) ← shared
   (`lib`, `components`, `stores`) ← `features/<name>` ← `app`. Only `api/` folders may import the
   backend. Features never import each other. Use `@/` for imports across folders. ESLint
   enforces this; **never disable `no-restricted-imports`**. Move the code instead.
2. **`core/` stays pure**: no DOM, React, I/O or timers except the injected ones.
3. **Only `src/pdf/document.ts` calls MuPDF.** Everything else goes through `pdfClient`.
4. **Schema changes add a Dexie version** with an upgrade and a test against the old version.
   Never edit an existing version, and never re-parse books in a migration.
5. **Branch on `book.layout.kind`**, never on whether a field happens to be present.
6. **Pacing and ORP match the Python original** (`v-legacy` tag). Don't change their output
   unless that's the task.
7. **Move files and change behaviour in separate commits.**
8. A bug fix includes a test that fails without it. Put testable logic in pure functions
   (`*.ts` next to the component) and test those.

## Don't touch

- `android/` and `src-tauri/gen/`: generated by Capacitor and Tauri. The exception is the
  version lines in `android/app/build.gradle` during a release.
- `public/ocr/`: copied by `scripts/copy-ocr-assets.mjs`.
- `tests/fixtures/`: add new fixtures if needed, but don't edit existing ones.
- `docs/architecture/decisions.md`: append only, never rewrite past entries.
- `docs/architecture/archive/`: history.

## Git

- Don't commit or push unless asked. Never force-push `main`.
- No AI attribution in commits or PRs: no `Co-Authored-By` lines, no "Generated with" footers.
- Commit subjects are a plain imperative sentence, with no `feat:` prefixes.
- Releases: see CONTRIBUTING.md. The draft release must exist before the tag is pushed.

## Keep docs true

If your change makes a sentence in ARCHITECTURE.md or docs/architecture/ wrong, fix it in the
same change. Record non-obvious decisions in `docs/architecture/decisions.md`.
